# AI-Powered Product Recommendation & Review Analysis System

## 1. Project Overview

An AI/ML-powered system for product recommendation and customer
review analysis.

The system combines:

- Product recommendation
- Customer interaction analysis
- Sentiment classification
- MLflow experiment tracking
- MLflow Model Registry
- LLM-based review analysis
- FastAPI REST APIs
- Docker deployment

## 2. Problem Statement

E-commerce platforms generate large amounts of customer interaction
and review data. This project aims to use that information to provide
personalized product recommendations and extract useful insights
from customer reviews.

## 3. Objectives

- Build a product recommendation system.
- Build a customer review sentiment classifier.
- Compare multiple ML models.
- Track experiments using MLflow.
- Register the selected model.
- Generate higher-level review insights using an LLM.
- Expose functionality through FastAPI.
- Containerize the application using Docker.
